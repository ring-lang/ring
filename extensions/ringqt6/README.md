RingQt6 Extension
=================

The folder "Classes" contains configuration files (.cf) that define each Qt class.

The folder "Events" contains Ring files that define each Qt class signals and slots.

The folder "Cpp" contains the generated code (Don't modify it directly) - generated by the code generator.

The folder "Docs" contains scripts that generate the documentation of this extension.

How to study this extension
===========================

(1) Start by looking at the classes/qt.cf file.

(2) Then look at events/qtevents.ring 

How to build for Qt 6.12 (Windows x64 MSVC)
===========================================

(1) Generate C++ code:

    gencode_core_qt6.bat        (Core only build)
    gencode_light_qt6.bat       (GUI + Widgets build)
    gencode_nobluetooth_qt6.bat (Full build without Bluetooth/WebEngine)

(2) Build the DLL:

    buildvc_core_qt6.bat        -> produces ringqt_core.dll
    buildvc_light_qt6.bat       -> produces ringqt_light.dll
    buildvc_nobluetooth_qt6.bat -> produces ringqt.dll (full without BT)

Runtime Files
=============

The ring/bin folder must contain Qt6 runtime DLLs. 

Run:

    cd binupdate
    installqt6.bat
