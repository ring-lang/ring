=====================
RingSockets Extension
=====================

In this chapter we will learn about using the RingSockets extension.

.. index:: 
	pair: sockets; TCP Server

TCP Server
==========

Example (TCP Server Code): 

.. code-block:: ring

	load "sockets.ring" 

	sock = socket(AF_INET,SOCK_STREAM,0) 
	setsockopt(sock,SOL_SOCKET,SO_REUSEADDR,1)
	bind(sock,"127.0.0.1",5050)
	listen(sock,5)
	ns = accept(sock)

	send(ns,"Hello Client")
	msg = recv(ns,1024)
	? "Client Say >> " + msg
	close(ns)
	close(sock)
	? "socket connection closed"

TCP Client
==========

Example (TCP Client Code):

.. code-block:: ring

	load "sockets.ring" 

	sock = socket(AF_INET,SOCK_STREAM)
	connect(sock,"127.0.0.1",5050)

	send(sock,"Hello Server")
	msg = recv(sock,1024)
	? "Server Say >> " + msg

	close(sock)
	? "socket connection closed"

UDP Echo Server
===============

``recvfrom`` stores the sender address, so ``sendto`` can reply without
passing a destination.

Example (UDP Echo Server Code):

.. code-block:: ring

	load "sockets.ring" 

	sock = socket(AF_INET,SOCK_DGRAM,0)
	bind(sock,"127.0.0.1",9090)

	while true
		msg = recvfrom(sock,1024)
		? "client >> " + msg
		sendto(sock,"echo: " + msg)
	end

	close(sock)

.. index:: 
	pair: sockets; UDP Client

UDP Client
==========

``connect`` on a UDP socket only sets the default destination, so
``send``/``recv`` can be used instead of ``sendto``/``recvfrom``.

Example (UDP Client Code):

.. code-block:: ring

	load "sockets.ring" 

	sock = socket(AF_INET,SOCK_DGRAM,0)

	if connect(sock,"127.0.0.1",9090) = 0
		send(sock,"hello udp")
		? "server >> " + recv(sock,1024)
	ok

	close(sock)

Non-blocking I/O and select()
=============================

A socket set non-blocking never blocks in ``send``/``recv``/``accept``.
Use ``select()`` to wait until sockets are ready, and ``socklasterror()``
to detect the temporary "would block" condition.

Example (using ``socketpair`` so no second process is needed):

.. code-block:: ring

	load "sockets.ring"

	sp = socketpair(AF_UNIX,SOCK_STREAM,0)
	s1 = sp[1]
	s2 = sp[2]
	setnonblocking(s1,1)
	setnonblocking(s2,1)

	send(s1,"ping")

	# wait (up to 1 second) until s2 is ready to read
	r = []
	add(r,s2)
	ready = select(r,[],[],1)
	? len(ready[1])            # 1

	? recv(s2,100)             # ping

	d = recv(s2,100)           # nothing left to read
	? isnull(d)                # 1 = would block
	? socklasterror() = SOCK_EWOULDBLOCK   # 1

	close(s1)
	close(s2)

Utility Functions
=================

Example (byte order, address conversion, getsockopt, getpeername, shutdownsocket):

.. code-block:: ring

	load "sockets.ring"

	? htons(80)                    # host -> network byte order
	? ntohs(htons(80))             # back -> 80

	packed = inet_addr("127.0.0.1")    # 4 binary bytes
	? inet_ntoa(packed)                # 127.0.0.1

	server = socket(AF_INET,SOCK_STREAM,0)
	setsockopt(server,SOL_SOCKET,SO_REUSEADDR,1)
	? getsockopt(server,SOL_SOCKET,SO_TYPE)    # 1 = SOCK_STREAM

	bind(server,"127.0.0.1",5060)
	listen(server,1)
	client = socket(AF_INET,SOCK_STREAM,0)
	connect(client,"127.0.0.1",5060)
	conn = accept(server)

	? getpeername(client)          # 127.0.0.1 , 5060

	shutdownsocket(client,SHUT_RDWR)
	? recv(conn,100)               # "" = peer closed

	close(conn)
	close(client)
	close(server)
	socketsCleanup()

Functions
=========

The next functions are provided by this extension

.. code-block:: none

	socket(nAddressFamily, nConnectionType [, nProtocol]) -> SocketHandle
	socketfd(pSocketHandle) -> nFileDescriptor
	setsockopt(pSocketHandle, nLevel, nOptionName, nValue)
	getsockopt(pSocketHandle, nLevel, nOptionName) -> nOptionValue
	bind(pSocketHandle, cHost , nPort)
	listen(pSocketHandle [, nBacklog])    # nBacklog default = 5
	accept(pSocketHandle) -> pConnectionHandle
	send(pConnectionHandle|pSocketHandle, cMessage [, nFlags]) -> nBytesSent
	sendto(pSocketHandle, cMessage [, nFlags] | cHost, nPort [, nFlags]) -> nBytesSent
	recv(pConnectionHandle|pSocketHandle, nBuffer [, nFlags]) -> cData
	recvfrom(pSocketHandle, nBuffer [, nFlags]) -> cData
	connect(pSocketHandle, cHost , nPort) -> return <0> if successful
	close(pSocketHandle|pConnectionHandle)
	shutdownsocket(pSocketHandle, nHow) -> nHow = SHUT_RD | SHUT_WR | SHUT_RDWR
	setnonblocking(pSocketHandle, nFlag) -> nFlag = 1 (non-blocking) or 0 (blocking)
	select(pReadList, pWriteList, pExceptList [, nTimeout]) -> list of 3 lists
	socklasterror() -> nLastSocketErrorCode
	getaddrinfo(cHost, cService [, nFamily]) -> list of {family, socktype, protocol, ip, port}
	getsockname(pSocketHandle) -> list of {ip, port}
	getpeername(pSocketHandle) -> list of {ip, port}
	socketpair([nFamily, nType, nProtocol]) -> list of two SocketHandles (on Windows the arguments are ignored and a TCP loopback pair is returned)
	getprotobyname(cName) -> nProtocolNumber
	gethostbyname(cHostName) -> cIPAddress
	gethostbyaddr(cIPAddress) -> aListOfHostInfo
	gethostname() -> cHostName
	getservbyname(cName) -> nPort
	getservbyport(nPort) -> cName
	ntohs(nNetshort) -> nHostshort
	htons(nHostshort) -> nNetshort
	htonl(nHostlong) -> nNetlong
	ntohl(nNetlong) -> nHostlong
	inet_addr(cIP) -> packed_address (4 binary bytes)
	inet_ntoa(packed_address) -> cIP
	inet_pton(AdressFamily, IP) ->  packed_address
	inet_ntop(AdressFamily, packed_address) -> IP
	socketsCleanup()

Notes:

* ``send`` / ``sendto`` return the number of bytes sent and raise an error on failure.
* ``recv`` / ``recvfrom`` return the received data and raise an error on failure.
* The optional ``nFlags`` parameter accepts the ``MSG_*`` constants (see below).
* ``sendto`` may be called with an explicit destination (``cHost, nPort``); otherwise it
  replies to the last ``recvfrom`` source or a ``connect`` ed socket.
* ``socketfd`` returns the underlying operating-system file descriptor of the socket,
  useful when interoperating with other extensions.
* With ``setnonblocking(sock, 1)``, ``send``/``recv``/``sendto``/``recvfrom``/``accept``
  do not block. On a temporary "would block" condition they return without error;
  check ``socklasterror()``: ``recv``/``recvfrom``/``accept`` return NULL (nothing),
  ``send``/``sendto`` return ``-2``, and ``socklasterror() == SOCK_EWOULDBLOCK`` means
  "retry after ``select()``". An empty string from ``recv``/``recvfrom`` means the peer
  closed the connection.

Example:

.. code-block:: ring

	load "sockets.ring"

	host = gethostbyname("google.com")
	? host
	line()
	? gethostbyaddr(host)
	line()
	? gethostname()
	line()
	? getservbyname("ftp")
	line()
	? getservbyport(21)

	func line ? copy("=",30)
