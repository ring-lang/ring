RingTest Package
================

RingTest is a modern, ultra-fast, and lightweight unit testing framework and test runner.

Install:

.. code-block:: none

	ringpm install ringtest

Example:

.. code-block:: ring

	describe("Math Operations", func {

		it("should add numbers correctly", func {
			expect(10 + 20).toBe(30)
		})

		test("should compare numerical bounds", func {
			expect(100).toBeGreaterThanOrEqual(100)
			expect(25).toBeLessThan(50)
		})

		it("should catch runtime exceptions", func {
			expect("1 / 0").toThrowError("Zero")
		})

	})

Output:

	:alt: RingTest

XMLLib Package
==============

Pure Ring library for building and parsing XML documents.

Install:

.. code-block:: none

	ringpm install xmllib

Example:

.. code-block:: ring

	load "xmllib.ring"

	? "Demo 12: Build from Ring lists..."

	oXml = new XMLWriter
	oXml.addDeclaration()

	# Build person from list
	oXml.addFromList("person", [
		["name", "Adam"],
		["email", "adam@example.com"],
		["phone", "+20-123-456-7890"]
	])

	? oXml.output()
	? ""

	# Multiple items with same tag
	oXml2 = new XMLWriter
	oXml2.startElement("fruits")
	oXml2.addListAsElements("fruit", ["Apple", "Banana", "Cherry", "Date"])
	oXml2.endElement()

	? oXml2.output()

Better Switch Statement
=======================

A case in the Switch statement can have many expressions separated by commas, like (case 1, 2).

Example:

.. code-block:: ring

	aDays = ["Sun","Mon","Tue","Wed","Thu","Fri","Sat"]

	for nDay = 1 to len(aDays)
		switch nDay
		case 1, 7
			? aDays[nDay] + " : Weekend"
		case 2, 3, 4, 5, 6
			? aDays[nDay] + " : Workday"
		end
	next

	for cColor in ["red", "green", "black"]
		switch cColor
		case "red", "green", "blue"
			? cColor + " : Primary color"
		else
			? cColor + " : Other color"
		end
	next

Output:

.. code-block:: none

	Sun : Weekend
	Mon : Workday
	Tue : Workday
	Wed : Workday
	Thu : Workday
	Fri : Workday
	Sat : Weekend
	red : Primary color
	green : Primary color
	black : Other color

Better Ring API
===============

Added: RING_API_REGISTERLENDSTRING(cFunctionName,pFunctionPointer)

RING_API_REGISTERLENDSTRING registers a C function in the Ring VM, just like RING_API_REGISTER,
and also tells the VM that the function only reads its string parameters: it doesn't change them,
and it doesn't keep them after it returns.

When such a function is called with a string variable as a parameter, the Ring VM can lend the
string of the variable to the function instead of copying it. This avoids allocating and copying
the string, which is faster when the function is called many times or the string is large.

The VM lends the string only when nothing between loading the function and calling it can change
the variable (the parameters are numbers, literals or variables). Otherwise, the string is copied
as before.

.. tip:: Use RING_API_REGISTER for functions that change their string parameters or keep them.

Example:

.. code-block:: none

	RING_API_REGISTERLENDSTRING("left", ring_vm_generallib_left);
	RING_API_REGISTERLENDSTRING("right", ring_vm_generallib_right);
